# someday club.

Protótipo navegável mobile-first para organizar encontros entre amigos. Tema dark, estética indie/editorial e textos em português.

## Rodar localmente

1. Instale Node.js 20 ou superior.
2. Na pasta do projeto, execute `npm install`.
3. Execute `npm run dev`.
4. Abra o endereço local informado pelo Vite.

## O que já funciona no protótipo

- Navegação entre Início, Calendário, Encontrar datas, Rolês e Meu espaço.
- Calendário mensal com navegação entre meses e seleção de dia.
- Filtros demonstrativos de disponibilidade e duração.
- Criação local de sugestões de rolê.
- Votação e comentários nos eventos.
- Preferências locais de privacidade, notificações e exceção de disponibilidade.
- Layout responsivo com navegação inferior em telas pequenas.

## Ainda não conectado

Google Calendar/OAuth, autenticação real, banco de dados, push notifications, previsão meteorológica e IA externa. Os dados atuais são demonstrativos e ficam apenas no estado da interface.
